# Approved prototype: operator question v1

Disposition: reference-only. The user approved this page on 2026-09-23. It is evidence, not an implementation base.

## Confirmed

- The question panel sits at the bottom, in place of the input.
- The transcript stays above it.
- The header says how many questions are waiting, with elapsed time and token count.
- Options are numbered, with a radio and a description on the right.
- The active option is highlighted across the row.
- `z` is the free-text row.
- `Tab` moves to the next answer. `Esc` scrolls the transcript and leaves the panel open. It is not a refusal. `Shift+x` dismisses the panel and the tool receives a refusal.
- Answering does not launch a child.
