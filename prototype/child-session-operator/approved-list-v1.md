# Approved prototype: subagent list v1

Disposition: reference-only. The user approved this page on 2026-09-23. It replaces the gentle-shell card. It is evidence, not an implementation base.

## Confirmed

- The list lives in the transcript, not in a fixed card above the input.
- The header reads `Subagents` plus the count.
- Each row shows the name, the current step, the model, the effort, and the elapsed time.
- Effort also appears on the session input, as `Grok 4.7 (high)`.
- The active row is highlighted.
- Each row ends with `[↗]` and `[x]`.
- `[↗]` opens that child's transcript. `[x]` cancels that child.
- Near the input, the screen says how many children are still running.
