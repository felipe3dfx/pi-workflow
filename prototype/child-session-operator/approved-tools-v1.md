# Approved prototype: expanded tool or thought v1

Disposition: reference-only. The user approved this page on 2026-09-23. It is evidence, not an implementation base.

## Confirmed

- A closed tool or thought is one short line, such as `◆ Thought for 14.9s` or `◆ read`.
- Opening it shows the body under that title.
- A thick left bar encloses both the title and the body.
- `Enter` opens it. Left arrow or `Ctrl+e` closes it.
- Opening it does not change the file or the tool result.
