# Decision Recording

Only a scope change, whether a Work Contract addition or a scope expansion, a deviation from binding authority or the prototype contract, and an accepted risk need an append-only Spanish issue comment, published only once its approval preview is approved, where the policy asks. Knowingly breaking a binding standard is an accepted risk; rejecting a finding that cites a binding requirement is a deviation. Every other decision, technical ones included, stays in the commit body and never reaches the tracker.

Each comment follows the tracker playbook's comment shape. A deviation or scope change names the affected acceptance criterion in the ticket's own wording; a Work Contract addition states the new behavior as one verifiable criterion in that wording. A decision that narrows a binding criterion is published as that deviation comment before step 4, so the Spec axis judges it.
