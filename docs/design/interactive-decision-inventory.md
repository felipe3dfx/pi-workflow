ILA-2474 may remove legacy paths only when every non-pending row has a shared descriptor, a visible `Cancelar` action, an equivalent numbered fallback, a workflow manifest bound to the leased `executionId`, and public tests proving that cancellation, custom feedback, malformed output and missing UI cause zero new product mutations.
