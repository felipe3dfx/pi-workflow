Cada fila separa la base de evidencia canónica (`demonstrated failure`, `substantiated risk` o `speculative`) del tema, la severidad original, la evidencia, necesidad, impacto, complejidad, responsable, recomendación y disposición. Las recomendaciones originalmente descritas como detalles de especificación se normalizan como `speculative`: no afirman un fallo demostrado. NC6 conserva la advertencia consolidada sustentada por la evidencia de recorte de factibilidad F5; la observación original de necesidad sobre ampliar el alcance era especulativa. Esta normalización la realiza el padre sobre las conclusiones que presenció; no atribuye clasificaciones nuevas a las lentes ni afirma corroborar transcripciones ausentes. «Corregido» significa que la restricción está registrada en el especificación, no que esté implementada o probada. Responsables: implementación = futuro equipo ejecutor; decisión = usuario; definición = síntesis del paquete. La complejidad es una valoración cualitativa del tratamiento, no una estimación de esfuerzo validada.
