# Coding Standards

This repository's own coding standards, read only by the review's Standards axis. The team's standards ship with `code-review`; record here only what is specific to this repository.

## Standards

- Code, identifiers, comments, tests, fixtures, and package documentation are written in English; stable identifiers, hashes, schema names, code symbols, and exact technical terms stay unchanged when translation would break identity.
- Runtime code never claims to prove professional-neutral Spanish through NLP, dictionaries, regionalism lists, foreign-word checks, or similar language heuristics.
