# Ticket: incorporar un archivo CHANGELOG.md

## Descripción

Se solicita incorporar un archivo `CHANGELOG.md` en la raíz del proyecto para documentar los cambios relevantes de la herramienta CLI que convierte archivos CSV a JSON. El archivo deberá facilitar el seguimiento de las modificaciones entre versiones y servir como referencia para las personas usuarias y mantenedoras.

## Criterios de aceptación

1. Existe un archivo `CHANGELOG.md` en la raíz del proyecto, redactado en español y con un título identificable.
2. El archivo incluye una sección para cambios aún no publicados y organiza las entradas por versión y fecha cuando corresponda.
3. El archivo documenta los cambios relevantes disponibles sin atribuir versiones, fechas ni funcionalidades que no puedan verificarse.

## Riesgos

- La información histórica disponible podría ser incompleta, lo que dificultaría la reconstrucción fiable de cambios anteriores.
- La falta de actualización continua del archivo podría generar discrepancias entre la documentación y el estado real del proyecto.
